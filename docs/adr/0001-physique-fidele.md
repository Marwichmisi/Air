# Physique fidèle : recoder les formules

La spec décrit déjà le pas de temps, les masses et le ressort du doigt. La salle propre recode ces formules pour viser les mêmes trajectoires. Elle ne règle pas librement la physique de Godot pour obtenir seulement un ressenti proche.

Un écart invisible reste acceptable. Les points encore ouverts ne sont pas inventés.

## Considéré

- Recoder les formules. Retenu : les nombres sont déjà écrits, et changer de physique plus tard coûterait cher.
- Régler seulement le ressenti. Écarté : ça laisse tomber la spec.
- Exiger une copie image par image. Écarté : aucun enregistrement des trajectoires ne sert de référence.
